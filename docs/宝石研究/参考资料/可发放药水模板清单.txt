# 可发放为「魔法剂」的模板清单（带 PotionType）

> 2026-10-10 实测确定。`getfixedpotion <模板名> [档位]` 能把模板造成**药剂形态**并直接入袋；
> **能否成功 = 该模板是否定义了 `PotionType`**（`SwordInventoryItemGem.PotionType`）。
> 依据：9 个无 PotionType 的模板（UberFireGem / UberAttackGem / UberMagicGem / UberElementalGemMax /
> RainbowElementalAttackGem / UberIceGem / UberLightGem / UberGoldGem / UberXPGem）**全部失败**；
> 5 个有 PotionType 的（FireGem / AttackGem / UberElementalAttackGem / UberBossGem_3 / UberSwitchClass）**全部成功**。

数据源：`E:\Infinity Blade\Ⅲ\SwordGame\Config\DefaultGems.ini`（164 个模板中 90 个带 PotionType）

## 说明

- **专用药剂模板**（`Potion_*`，8 个）就在上表内：HealthRegen(1) / ElementalDefense(1) / SecondChance(1) /
  UnlimitedDodge(2) / ShieldRegen(3) / BlockAll(4) / DoubleXP(4) / ParryAll(4)。
- 其余是**把宝石模板强制成药水形态**：显示名由本地化的生成模板拼出
  （`StatPotionName=%type% 属性魔法` / `ElementalDamagePotionName=%type% 攻击魔法` /
  `ElementalDefensePotionName=%type% 防御魔法` / `GenericPotion=%type% 魔法剂` / `PotionName=%type% %effect% 魔法`）。
  例：`FireGem` 强制成药水后在游戏里显示为 **FIRE ATTACK POTION**（实测）。
- **元素族可用的**：FireGem / IceGem / ElecGem / PoisonGem / LightGem / DarkGem / WaterGem / WindGem /
  HealthGem / ShieldGem / MagicGem / AttackGem（基础族）与 UberElementalAttackGem（多元素）。
  ⚠ Uber 级元素宝石（UberFireGem 等）**没有 PotionType，发不出来**。
- 档位：`getfixedpotion <名> <n>` 里的 n 会写进 `GemTier`（实测 0 / 2 生效，显示数值随之变化）。
