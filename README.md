# 无尽之剑Ⅲ 修改器（IB3 Trainer）

> 为《Infinity Blade III》PC 移植版做的**单机离线**修改器。零控制台注入、自动附着游戏进程，
> 覆盖金币/筹码、四项属性、等级与技能点、物品发放、宝石档位与背包、掌握升阶、通用内存扫描。
> 中英双语界面，单个 exe，无需安装。

## 功能总览

| 页签 | 功能 |
|---|---|
| **战斗·商店** | 无敌开关、充满超能与魔法、击杀当前 Boss（战斗中）、金币/筹码直写、商店刷新一轮稀有宝石、触发龙战/收藏家 |
| **物品发放** | 按分类浏览全部物品；按类型走正确通道发放 —— 装备/藏宝图直入背包，宝石刷进随身商店，材料/药水/钥匙/抽奖箱加数量 |
| **宝石·背包** | 列出背包与随身商店的全部宝石（模板名 / Tier / 融合标记 / 随机加成 / 当前显示值 / 地址），可改成目标显示值或目标 Tier |
| **成长** | 体力 / 护盾 / 攻击 / 魔法 / 等级 / 技能点 / 生命 / 最大生命的读取、写入、锁定；掌握升阶 |
| **发现模式** | 通用内存扫描工作台（首扫 / 筛选 / 快照 / 差分 / 试写），供进阶排查 |
| **换存档** | 自动检测存档切换并重新绑定 |

**特点**

- **零控制台注入** —— 不打开游戏控制台、不抢焦点、不发送按键
- **自动附着** —— 检测到游戏进程后按「真身」结构自动绑定金币/筹码/四维/等级等地址，无需手动找址
- **安全闸** —— 写入前当场重新定位，地址失效或数组未装载时**直接拒绝写入**并说明原因，而不是报一个假的成功
- **中英双语** —— 按系统语言自动判定，标题条右侧一键切换，选择记在 `ib3_ui.ini`
- **单个 exe** —— 无安装程序、无运行库依赖（只用 Windows 自带的 .NET Framework 与 `csc.exe`）

## 下载与安装

到 **[Releases](https://github.com/Tongyonyuen/ib3-trainer/releases)** 下载最新的成品压缩包，解压到任意目录（路径避免特殊符号），然后：

1. 双击运行 **`IB3训练器2.exe`**
2. 点左下角 **「游戏目录…」** → 选择 **`Infinity Blade Launcher.exe` 所在的文件夹**（通常是 `你的游戏目录\Binaries`）
   - 修改器会记住游戏位置，并把随包的 `SwordGame.upk` 替换到 `游戏目录\SwordGame\CookedPCConsole\SwordGame.upk`（原文件自动备份为 `SwordGame.upk.orig`）
   - **替换 upk 是必须的**：物品发放、掌握升阶等命令依赖它才能生效。若提示「游戏正在运行」，请先关闭游戏再重新选择
3. 点 **「启动游戏（中文）」** → 游戏启动后会**自动附着**（状态栏显示「已附着」），即可开始使用

详细的逐功能说明、硬约束与 FAQ 见 **[使用说明](docs/使用说明.md)**。

## 从源码构建

不需要 MSBuild、不需要 NuGet、不需要 Visual Studio —— **只用 Windows 自带的 .NET Framework 编译器**。

```sh
cd src/ib3trainer2
sh build.sh            # 主程序 → IB3训练器2.exe
sh build.sh test       # 引擎自检（enginetest2.exe），游戏未运行时会跳过实况项
sh build.sh gemtest    # 宝石定位自检（gemselftest.exe），只读，不写目标进程
sh build.sh probe      # 只读地址探针（addrprobe.exe）
```

`build.sh` 调用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（Windows 内置）。语言级别上限为 **C# 5**，
所以源码里不能用字符串插值、`?.`、`out var`、表达式体成员 —— 这不是疏忽，见 `I18n.cs` 头部的约束注释。

**构建依赖**：无第三方库。新增 `.cs` 文件必须手工加进 `build.sh` 的 `SRC` 列表。

> **注意**：本仓库源码树**不包含** `ib3_gems.ini` 与 `SwordGame.upk`（它们是游戏数据，只随 Release 成品包分发）。
> `SwordGame.upk` 只在运行「游戏目录…」时用到；`ib3_gems.ini` 是**运行时必需**的宝石公式库，缺了程序会打印
> `⚠ 未找到 ib3_gems.ini` 并降级运行。要跑完整功能，请把 Release 包里的 `ib3_gems.ini` 放到 exe 同目录。

## 已知限制

- 修改器**只针对特定版本的游戏**。版本不符时它只会失效或拒绝操作，不会乱改内存。
- 宝石列表的**名字是按存档位对齐贴上去的**。游戏内背包一旦变动（融合/买卖/换装），列表就会错位 ——
  错位意味着「你看着是这颗、改的是那颗」。所以每次读取/应用前请先在游戏里存一次档（切一次场景）。
- 改宝石 Tier 会同时把该宝石标记为「已融合」（`CookedGemVar=50`），这是让游戏承认 Tier 的必要条件，但**是持久改动**。
- 地址簿 `ib3_addrs.ini` 由程序自动生成，里面的地址是**每台机器、每次运行都不同**的内存位置 ——
  **不要在不同用户之间传递这个文件**，发给别人反而会写坏内存。
